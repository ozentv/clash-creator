# Icônes des unités

Dépose ici les images des héros, troupes, sorts, familiers, engins de siège et équipements.
Elles s'affichent automatiquement dans la fiche joueur (onglet « Armée ») après un nouveau build ;
une unité sans image garde sa pastille à initiales.

- Formats acceptés : `.png`, `.webp`, `.svg`, `.jpg`
- Taille conseillée : carrée, 96 × 96 px ou plus
- Nom du fichier : le nom **anglais** de l'unité tel que le renvoie l'API, en minuscules,
  tout ce qui n'est pas une lettre ou un chiffre remplacé par un tiret.

| Unité (API) | Fichier |
| --- | --- |
| Barbarian King | `barbarian-king.png` |
| Archer Queen | `archer-queen.png` |
| P.E.K.K.A | `p-e-k-k-a.png` |
| L.A.S.S.I | `l-a-s-s-i.png` |
| Wall Breaker | `wall-breaker.png` |
| Lightning Spell | `lightning-spell.png` |
| Giant Gauntlet | `giant-gauntlet.png` |
| Super Barbarian | `super-barbarian.png` |

L'API Clash of Clans ne fournit pas ces images. Supercell en met à disposition dans son kit
pour les fans ; leur utilisation est encadrée par sa politique de contenu des fans
(https://supercell.com/en/fan-content-policy/).
